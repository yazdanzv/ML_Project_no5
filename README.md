# ML_Project_no5

## Code guide

`main.ipynb` contains the numbered homework questions. It loads and normalizes data, prepares numerical features, and performs the analyses in the notebook's Question 1 and Question 2 sections. `Homework 05.pdf` is the assignment sheet and `Report.docx` is the written report. Open the notebook from the repository root, install the libraries imported in its first cells, and run cells in order. The saved outputs were not regenerated for this README.
